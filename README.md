# Clinica_Estetica

## Tecnologias utilizadas

- PHP
- MySQL
- XAMPP
- HTML
- CSS

## Como executar

1. Instale o XAMPP.
2. Inicie o Apache e o MySQL.
3. Copie a pasta do projeto para `htdocs`.
4. Importe os arquivo no MySQL.
5. Execute os scripts de procedures, functions e views.
6. Acesse no navegador:

http://localhost/Clinica_Estetica/
